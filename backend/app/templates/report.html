5. NIST Post-Quantum Standards Reference

FIPS 203 (August 2024) — ML-KEM (Module-Lattice Key Encapsulation Mechanism): Based on CRYSTALS-Kyber. Three security levels: ML-KEM-512 (Level 1), ML-KEM-768 (Level 3), ML-KEM-1024 (Level 5). Use for: TLS 1.3 key exchange, VPN, SSH, encrypted storage, HTTPS.
https://doi.org/10.6028/NIST.FIPS.203
FIPS 204 (August 2024) — ML-DSA (Module-Lattice Digital Signature Algorithm): Based on CRYSTALS-Dilithium. Three security levels: ML-DSA-44, ML-DSA-65 (Level 3), ML-DSA-87. Use for: digital signatures, PKI certificates, JWT signing, code signing.
https://doi.org/10.6028/NIST.FIPS.204
FIPS 205 (August 2024) — SLH-DSA (Stateless Hash-Based Digital Signature Algorithm): Based on SPHINCS+. Hash-based — security relies only on hash function security, not lattices. Use for: firmware signing, long-term archive signatures, certificate roots.
https://doi.org/10.6028/NIST.FIPS.205
