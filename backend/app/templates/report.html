5.0 Regulatory Standards Baseline & Formal Attestation

NIST FIPS 203 (Finalised August 2024) — ML-KEM (Module-Lattice Key Encapsulation): Primary national standard derived from CRYSTALS-Kyber. Defines ML-KEM-512 (Category 1), ML-KEM-768 (Category 3 — Enterprise Target), and ML-KEM-1024 (Category 5). Scope: TLS 1.3, VPN tunnels, HTTPS, database transport encryption, and secure file exchange.
Official Reference: DOI: 10.6028/NIST.FIPS.203 (https://doi.org/10.6028/NIST.FIPS.203)
NIST FIPS 204 (Finalised August 2024) — ML-DSA (Module-Lattice Digital Signatures): Primary signature standard derived from CRYSTALS-Dilithium. Defines ML-DSA-44, ML-DSA-65 (Category 3 — Recommended), and ML-DSA-87. Scope: Public Key Infrastructure (PKI), X.509 certificate generation, JWT assertion signing, and code-signing pipelines.
Official Reference: DOI: 10.6028/NIST.FIPS.204 (https://doi.org/10.6028/NIST.FIPS.204)
NIST FIPS 205 (Finalised August 2024) — SLH-DSA (Stateless Hash-Based Signatures): Stateless hash-based signature scheme derived from SPHINCS+. Security relies solely on cryptographic hash collision resistance. Scope: Root Certificate Authorities, firmware integrity signing, and secure archival records with >20-year shelf life.
Official Reference: DOI: 10.6028/NIST.FIPS.205 (https://doi.org/10.6028/NIST.FIPS.205)

Recommended Implementation Libraries: Production engineering teams should target liboqs-python (Open Quantum Safe project) or native OpenSSL 3.4+ providers supporting FIPS 203/204/205 algorithms.
